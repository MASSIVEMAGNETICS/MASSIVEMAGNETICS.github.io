The recovered catalog

One pass turns folder chaos into evidence.

You receive usable files, not a dashboard subscription or a cleanup gamble.

01 / INVENTORY

Every supported audio path

Recursive inventory records filename, location, byte size, modified time, SHA-256, format, duration, sample rate, channels, bitrate, and embedded tags when readable.

02 / DUPLICATES

Byte-identical groups

Copies that contain the same bytes receive the same cryptographic hash and appear together with potential reclaimable space. Nothing is deleted.

03 / GAPS

Metadata and file issues

Missing tags, corrupt containers, unreadable paths, symlinks, and files changing mid-scan stay visible instead of disappearing behind a false clean result.

04 / SEARCH

A catalog you can query

Search paths, titles, artists, albums, genres, composers, ISRCs, and hashes in the desktop app or the owner-controlled SQLite file.

05 / EXPORT

Portable reports

Open the flat catalog in a spreadsheet, preserve the JSON as machine-readable evidence, and use the duplicate and issue files as bounded work queues.

06 / RECEIPT

Reports that verify

The scan receipt records a SHA-256 checksum and byte length for every standard report so later changes can be detected.

What is the refund rule?

Cancel before the guided session for a full refund. If the tool cannot produce a readable catalog on the supported system and no usable report is delivered, request a full refund within seven calendar days. A completed usable catalog is not refundable solely because it finds few or no duplicates. Non-waivable consumer rights still apply.

What does seven days of support cover?

Installation, one scan or resume attempt, opening the catalog, and reading the included reports. New features, audio repair, metadata correction, file reorganization, and additional roots require a separate scope.

Are exact duplicates the same as similar songs?

No. Exact means byte-for-byte identical. The same performance exported to two formats or with different embedded tags will produce different hashes and will not be called an exact duplicate.

Do you receive my audio?

No upload is required. The application runs locally. If you choose guided support, screen sharing may reveal filenames or metadata visible on your screen; you control what is shown. Do not email source audio, passwords, or cloud-drive credentials.
