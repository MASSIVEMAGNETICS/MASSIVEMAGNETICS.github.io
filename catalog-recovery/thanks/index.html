Catalog Recovery / Intake

Preserve the files. Start with the boundary.

This is the configured post-checkout route for a Founding Catalog Recovery Session.

1. Do not reorganize yet.

Keep the source folder in the state you want cataloged. The recovery tool will inventory it without renaming, deleting, moving, or retagging audio.

2. Download the verified desktop package.

Choose Windows, macOS, or Linux from the Catalog Recovery 0.1.0 release. The packages are not code-signed; compare the ZIP with SHA256SUMS.txt before opening it.

3. Send only the setup facts.

Email your operating system, rough audio-file count, storage type, and preferred scheduling windows. Do not attach audio, passwords, or cloud-drive credentials.

4. Choose a separate report folder.

The guided session will confirm a report destination outside the source catalog, run or resume the local scan, and review the outputs.
