Alpha mechanics

OLD-SCHOOL SIMPLE.
REAL PERSISTENCE.

01 / READ

Open by default

Anyone can browse the thread index. Public discussion is intentionally visible so the community can exist before a private platform account system does.

02 / POST

GitHub identity for Alpha

Starting or replying to a thread currently uses GitHub authentication. That gives us real authorship and moderation without pretending we already operate a finished identity backend.

03 / MIGRATE

Storage is replaceable

The final B Heard account graph can replace this persistence layer later. The board categories, public URLs, community norms, and event contract survive the migration.

Community boundary

BE HEARD.
DON'T BURY PEOPLE.

Do

Share your work, give useful feedback, collaborate, ask real questions, post legitimate opportunities, and disagree with ideas without turning people into targets.

Don't

No spam floods, impersonation, doxxing, threats, scams, manufactured engagement, malware, illegal sales, or posting private information without permission.

Moderation

Threads are public repository issues. B Heard Network may edit labels, close, lock, or remove material that violates the board boundary or applicable platform rules.
